step 1 : Get an esp ofc 😆  
step 2 : get a pc too lol 😅  
step 3 : be serious ,this is one's life at stake  
step 4 : Put the esp in hypnosis aka "Boot Mode" By plugging in the cable while pressing the boot button  
Step 5 : now open the Arduino IDE Select your respective board and then set the partition scheme to "BIG APP"  
Step 6 : we need to install the libraries listed in the prerequisites folder  
Step 7 : The Firmware file is located in the firmware folder copy the firmware change the ssid and password to your home WiFi network then change the AI api used too to your preference (me loves gemini flavour api 😋) . The one i used is from HackClub Ai which gives 3$ api everyday for kiddos like me who are under 18 :) know more about it [here](https://ai.hackclub.com/)  
Step 8 : Compile and Flash tha firmware :)
