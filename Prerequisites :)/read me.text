# ESP32 Library Installation Guide

## Libraries used by the project

The project contains these includes:

```cpp
#include <WiFi.h>
#include <HTTPClient.h>
#include <WiFiClientSecure.h>
#include <ArduinoJson.h>
#include <WebServer.h>
#include <ESPmDNS.h>
#include <ESP32BLECombo.h>
```

### 1. ESP32 Arduino Core — REQUIRED

Install the **ESP32 board package by Espressif** in Arduino IDE.

This provides:

```text
WiFi.h
HTTPClient.h
WiFiClientSecure.h
WebServer.h
ESPmDNS.h
```

You **DO NOT need to install these individually**.

#### Install:

1. Open Arduino IDE.
2. Go to:
   `Tools → Board → Boards Manager`
3. Search for:
   `esp32`
4. Install:
   `esp32 by Espressif Systems`
5. Select your ESP32 board from:
   `Tools → Board → esp32`

`HTTPClient`, for example, is bundled with the Arduino ESP32 core.

---

### 2. ArduinoJson — REQUIRED

This one is a separate library.

The project uses:

```cpp
#include <ArduinoJson.h>
```

#### Install through Arduino IDE:

1. Go to:
   `Sketch → Include Library → Manage Libraries`
2. Search for:
   `ArduinoJson`
3. Install the current **ArduinoJson 7** release.

Arduino's current library listing identifies ArduinoJson 7.4.3, and the official installation instructions recommend installing it through the Arduino IDE Library Manager.

---

### 3. ESP32BLECombo — INCLUDED WITH THE PROJECT

The project uses:

```cpp
#include <ESP32BLECombo.h>
```

**DO NOT install this from the Arduino Library Manager.**

The required library is already included in:

```text
prerequisites/
```

Look for the ESP32 BLE Combo library inside that folder.

Install it by either:

### Option A — ZIP installation

If the library is provided as a `.zip`:

1. Open Arduino IDE.
2. Go to:
   `Sketch → Include Library → Add .ZIP Library...`
3. Select the ESP32 BLE Combo ZIP from the `prerequisites` folder.
4. Restart Arduino IDE if necessary.

### Option B — Manual installation

If the prerequisites folder contains the library as a normal folder:

Copy the library folder into your Arduino libraries directory:

```text
Arduino/
└── libraries/
    └── ESP32BLECombo/
```

On Linux this is normally:

```text
~/Arduino/libraries/
```

Then restart Arduino IDE.

---

# Final Installation Checklist

You only need to install:

```text
[ REQUIRED ] ESP32 by Espressif Systems
[ REQUIRED ] ArduinoJson
[ REQUIRED ] ESP32BLECombo
             └── Already included in prerequisites/
```

You DO NOT need to separately install:

```text
WiFi.h
HTTPClient.h
WiFiClientSecure.h
WebServer.h
ESPmDNS.h
```

Those are supplied by the ESP32 Arduino core. The ESP32 core contains the networking/server libraries used by these headers.

## Minimum setup

Install **ESP32 by Espressif Systems**, install **ArduinoJson**, and install the **ESP32BLECombo library from the project's `prerequisites` folder**.

After that, the listed includes should be available.
